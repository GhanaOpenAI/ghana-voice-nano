# Ghana Voice Nano · Asante Twi

Static demo page for Asante Twi text-to-speech. It sends text to the Ghana Voice Nano API
(`serve/modal_app.py`: sherpa-onnx on CPU) and plays the returned audio.

- Model: [ghanaopenai/ghana-voice-nano-twi](https://huggingface.co/ghanaopenai/ghana-voice-nano-twi)
- Code, training recipe and mobile guide: [GhanaOpenAI/ghana-voice-nano](https://github.com/GhanaOpenAI/ghana-voice-nano)
